# marketplace
## Запуск проекта

1. Убедитесь, что у вас установлен Docker и Docker Compose
2. Клонируйте репозиторий, выбрать ветку dev
3. Выполните команду:
```bash
make start
```
Это запустит docker compose и запустит миграции
Сервер будет доступен по адресу http://localhost:8000/ <br>
Документация API (Swagger) доступна по адресу http://localhost:8000/docs
